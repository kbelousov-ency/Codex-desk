# История версий Codex Desk

Здесь описаны изменения публичных версий. Наличие раздела не означает публикацию: статус поставки и проверки находятся в [docs/RELEASES.md](docs/RELEASES.md), правила номеров — в [docs/VERSIONING.md](docs/VERSIONING.md).

## [0.7.0] — 2026-09-25

- После обновления Release появляется страница «Что нового?» с изменениями между установленной и новой версиями.
- Заметки работают без интернета, показывают пропущенные версии и остаются доступными позже через Ctrl+K.
- Состояние просмотра хранится отдельно от настроек, авторизации и истории; Nightly и Development не прерываются автоматическим показом страницы.

## [0.6.0] — 2026-09-24

- Обновление Codex CLI прямо из Codex Desk через штатный updater с автоматическим переподключением вкладок.
- Перечитывание каталога моделей после переподключения, чтобы новые модели CLI появлялись без ручного перезапуска.
- Индикатор read-only статистики роутера: лимиты, расход, остаток и дата сброса с сохранением неизвестных значений.
- Поддержка ledger-расхода роутера и безопасное обновление данных без передачи ключа в renderer.
## [0.5.1] — 2026-09-22

- Продолжение хода работы после ответа на уточняющий вопрос теперь показывается отдельным видимым блоком, даже если сервер сохраняет тот же `turnId`.
- Поздний echo сообщения пользователя сохраняет исходное место в переписке и не прячет последующие рассуждения, команды и изменения файлов.
- На завершающей странице установщика исправлен контраст пункта «Открыть Codex Desk» в тёмной теме; сохранены галочка, клавиатурный фокус и запуск приложения.

## [0.5.0] — 2026-09-22

- Перетаскивание файлов в окно и вставка из Проводника: изображения с превью, остальные файлы — путями в черновик.
- Автоматическое переподключение показано со спиннером и номером попытки; плашка закрывается при восстановлении ответа.
- Тематические вкладки настроек: агент, подключение, MCP и память; переключение сохраняет незавершённые поля и предпросмотр.
- Ответ с цитатой выделенного фрагмента сообщения и обсуждение выделенных строк diff.
- Оглавление диалога с поиском, своими подписями этапов и переходом к запросу.
- Закрепление файла, Markdown, изображения или снимка изменений рядом с чатом; обновление файла.
- Карточка результата запроса с файлами, командами, точными статусами и переходами к событиям.
- Индикатор нескольких бесед одной папки и пересечений подтверждённых изменений выполняющихся задач.
- Архив диалогов Claude Code: пункт «В архив», отдельный список приложения, чтение и восстановление. Транскрипты Claude не изменяются.

## [0.4.0] — 2026-09-21

- Правила ведения памяти в поставке: просмотр, включение и отключение отдельно для Codex и Claude через мастер и настройки, с сохранением пользовательских инструкций и резервными копиями.

## [0.3.0] — 2026-09-21

- Единые оформленные подсказки кнопок, файлов, вкладок и настроек.
- Выбор вариантов в вопросах агента нажатием, собственный ответ и отправка без потери черновика.
- Компактная оформленная подсказка версии с каналом, номером сборки и датой.
- Передача задачи между Codex и Claude Code с контекстом в новую вкладку той же рабочей папки.
- Загрузка полной доступной истории, выбор переписки или хода работы, просмотр и редактирование сообщения перед отправкой.

## [0.2.0] — 2026-09-21

- Периодическая проверка новых стабильных выпусков на GitHub и уведомление с предложением скачать обновление.
- Ручная проверка обновлений и настройки проверки в приложении.
- Единые правила номеров версий и подготовка проверенных файлов для GitHub Release.
- Копирование адреса ссылки через контекстное меню, в том числе для недоступных файлов и ссылок вне проекта.
- Исправлено повторное исчезновение значка приложения на панели задач Windows: постоянный файл ICO и восстановление привязки ярлыка.

Пользователям `0.1.0` необходимо один раз вручную скачать и установить эту версию: предыдущая версия ещё не умеет проверять обновления.

## [0.1.0] — 2026-09-21

- Первый публичный Windows x64 выпуск с отдельными агентами Codex CLI и Claude Code CLI, вкладками и сохранением рабочего места.
- История диалогов, поиск, файлы, изменения Git, изоляция задач, уведомления и диагностика.
- Установщик для текущего пользователя и мастер настройки CLI, конфигурации и входа.

История прежних локальных сборок под тем же номером, точные build ID, контрольные суммы и ограничения проверок сохранены в [docs/RELEASES.md](docs/RELEASES.md).
