# План разработки Кузьмича (Experimental 3) — концепт «дирижёр»

Зафиксировано 9 октября 2026 по решению владельца проекта.

## Концепт

- **Портал неприкосновенен.** Используются только закоммиченные ручки, живущие на проде (`coder-portal.encycam.com`). Незакоммиченный контракт Кузьмича (`api/kuzmich.py`, `Kuzmich.cs` и связанные правки) из репозитория Coder-Portal вырезается; резервная копия — `artifacts/portal-kuzmich-draft/`.
- **От пользователя — только авторизация.** Один вход в Portal в окне приложения (`electron/portal-auth-window.mjs`). Cookie сессии живёт только в main process и в renderer не попадает.
- **Максимум — на себе.** Всё, что портал позволяет сделать по cookie или по ключу роутера, Кузьмич делает программно: получение конфигурации Codex, подключение Claude, скачивание установщика Боцмана, лимиты.
- **Где портал требует человека — показываем, не обходим.** Окно штатного установщика Боцмана остаётся видимым. Подтверждения в трее Боцмана (`/api/boatswain/switch`) не используем как основной путь — конфигурация берётся напрямую по cookie.
- **Бренд и дизайн.** Источник правды — `Kuzmich_Design_System.md` (инженерный брутализм: графит + приглушённый зелёный, Russo One только для словомарки «Кузьмич», IBM Plex Sans/Mono для UI; без оранжевого, неона и «AI-клише»). Решение владельца 2026-10-09: везде, где видит пользователь, — «Кузьмич» кириллицей. Латиница остаётся только техническим идентификаторам: `Kuzmich.exe`, файл инсталлера `Kuzmich-Setup-*.exe`, `appId`, папка профиля `%APPDATA%\Kuzmich Experimental 3` (`release-channel.mjs:7` — это имя каталога на диске, переименование = потеря профиля пользователей).
- Принятое ограничение: пользователь с доступом только к Claude (без Codex) может не подключиться — портал проверяет Codex в существующих потоках. Принято владельцем.

## Принятые допущения (можно отменить)

1. **Боцман — опция** в мастере (галочка, по умолчанию включена): для подключения CLI он не нужен, нужен для скиллов/MCP с портала и уведомлений.
2. **Область подключения — глобальная для обоих CLI** (решение владельца 2026-10-09). Пишет её Кузьмич сам по данным cookie-ручек портала — **путь A**, выбран владельцем 2026-10-09 после приёмки В1: connect-скрипты портала (путь B) оказались интерактивными (`Read-Host` в `finally`, вероятный UAC, установка приложения Claude), что нарушает требование «только авторизация». Прежний app-scoped механизм (`router-connections.mjs` + env-overrides) остаётся для per-tab источников; `readClaudeConnection` из `boatswain-setup.mjs` читает итоговый settings.json для вкладок.

### Фаза 2 — подключение CLI одним входом (путь A, решение владельца 2026-10-09)
Рассматривался путь B (запуск connect-скриптов портала, как делает Боцман: `Switcher.cs` берёт токен `POST /api/relay/boatswain/connect/{product}` по ключу и исполняет `GET /api/connect/{product}/{token}.ps1`). Отвергнут после В1: скрипты интерактивны (`Read-Host` в `finally` всегда, `Confirm-Close` Y/N 60 с, вероятный UAC от `Enable-AppVm`, `claude.ps1` ставит и приложение Claude, `target:"on"` может увести в Microsoft Store). Путь B остаётся пользователю через трей Боцмана и кнопки кабинета — вне Кузьмича; маркеры совместимы, конфликтов нет (наш merge обязан повторять `codexcfg.keep_foreign` и `claudecfg.CLEARED`).

**Путь A — полностью программно после входа:**
- A3: `GET /api/key` (cookie; требовать `approved`) → Codex: `GET /api/codex/provider` + `/api/codex/defaults` по Bearer (готовый `router-portal.mjs`) → готовый preview/apply `portal-config.mjs` через config-API Codex CLI. Claude: `GET /api/config/claude?scope=global` (cookie) → merge `~/.claude/settings.json` с бэкапом: снять 6 имён `FOREIGN_AUTH`+`CLEARED` (спецификация в PORTAL_COMMITTED_API.md §4/§5a), наложить `settings.env`, остальное сохранить; реестровую политику приложения Claude не писать. Проверка: `GET {baseUrl}/models` с Bearer. Установка CLI — существующий `setup:install`.
- B3: шаг «Подключение» в мастере: per-CLI статусы, ошибки, повтор.
- Нюанс из В1: `/api/config/claude` выдаёт конфиг и по неодобренному ключу — успехом считать только с `approved: true`.
