# Отчёт Agent D: контекстное меню и копирование сообщений

## Файлы изменены

- `src/Conversation.tsx` — контекстное меню для пользовательских и ответов ассистента, копирование выделения/сообщения, клавиатурный вызов меню; существующая кнопка копирования переведена на общий helper.
- `src/Markdown.tsx` — оболочка тёмного блока кода с компактной кнопкой копирования полного содержимого блока и коротким состоянием «Скопировано».
- `src/messenger.css` — стили меню и заголовка блока кода в существующей тёмной зелёной визуальной системе.
- `src/clipboard.ts` — общий renderer helper поверх уже используемого `navigator.clipboard.writeText`.

## Поведение контекстного меню

ПКМ по текстовой области сообщения или ответа открывает небольшое меню в точке курсора. Если выделение целиком находится внутри нажатого сообщения, пункт копирует только выделенный текст и называется «Копировать выделенное». При отсутствии такого выделения пункт копирует текст конкретного сообщения/ответа. Ссылки и кнопки сохраняют собственное контекстное поведение; выделение текста не сбрасывается.

Меню закрывается кликом вне него или Escape. После открытия фокус переводится на пункт меню. Для сфокусированного сообщения работают `ContextMenu` и `Shift+F10`; сообщение получает доступный tab-фокус без изменения содержимого.

## Копирование блока кода

Каждый Markdown fenced code block получает компактную кнопку «Копировать» в заголовке. Копируется только текст его `<code>` содержимого, без заголовка, соседнего Markdown или других сообщений. После успешного копирования кнопка на 1,5 секунды показывает «Скопировано», затем возвращается к исходной подписи. Выделение, ссылки, изображения и прокрутка блока остаются обычными.

## Ограничения браузера/Electron

Копирование зависит от доступности `navigator.clipboard.writeText` в renderer-контексте и разрешений текущего BrowserWindow. При недоступном API helper возвращает ошибку; native clipboard для файлов и существующие Electron IPC операции не изменялись. Позиция меню ограничивается viewport, поэтому при узком окне оно может немного смещаться от точки ПКМ.
