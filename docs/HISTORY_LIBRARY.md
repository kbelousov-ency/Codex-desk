# Поиск сообщений и закладки — 2026-09-19

Пользователь поручил выполнить четыре следующих пункта: реальную проверку Claude, поиск содержимого истории, закладки и просмотр файлов. Эта заметка описывает второй и третий пункты. Прежние поиск названий и Ctrl+F сохранены в [CHAT_SEARCH.md](CHAT_SEARCH.md).

## Использование

«История и закладки» в левой панели открывает библиотеку. Поиск работает по тексту сообщений пользователя и ответов Codex/Claude в выбранном проекте; доступны фильтры проекта и агента, выдержки и переход к конкретному сообщению. Запрос буквальный, нечувствительный к регистру. История читается частями: «Искать дальше» продолжает поиск, счётчик накопительный. Архив Codex также включён; архив Claude пока не поддерживается самим приложением.

«В закладки» рядом с сообщением сохраняет ссылку на него и выдержку. Во вкладке «Закладки» можно задать собственную подпись, открыть источник или удалить закладку. Подпись сохраняется при уходе из поля; повторное сохранение сообщения без новой подписи сохраняет прежнюю. Закладки принадлежат профилю Codex Desk и переживают перезапуск. Удаление закладки не меняет историю агента.

Фильтр «Все проекты» в закладках включает закрытые и удалённые папки: выдержку и подпись можно читать и редактировать без доступного источника. При возврате к поиску снова выбирается конкретный проект.

Перед переходом читается актуальное состояние диалога: архив открывается для чтения, обычная беседа — в своей вкладке и у своего агента. Уже открытая вкладка используется повторно, черновик сохраняется. При необходимости подгружаются предыдущие страницы, целевое сообщение подсвечивается. Удалённый диалог или отсутствующее сообщение дают понятную ошибку; сохранённая выдержка остаётся. Архивирование и восстановление после создания закладки не привязывают её к устаревшему режиму открытия.

## Контракты и ограничения

- `electron/history-search.mjs` читает поддерживаемые native endpoints: Codex через отдельный read-only management App Server, Claude через официальный SDK history reader. Поиск не вызывает resume/start/turn и не меняет историю, auth/config или SQLite.
- Фиксированные workspace IPC: `searchHistory({cwd,provider,query,cursor?})`, `resolveHistoryTarget({cwd,provider,threadId})`, `listBookmarks`, `saveBookmark`, `removeBookmark`. Cwd поиска должен принадлежать открытым проектам; источник проверяется по provider/cwd/id. Viewer имеет отдельные scoped IPC.
- Поиск не включает системные, зашифрованные, reasoning и tool-блоки. Ctrl+F по уже отображённому чату остаётся более широким поиском по публичному содержимому UI. Постоянного полнотекстового индекса и копии всех бесед на диске нет.
- Один вызов: до 10 завершённых диалогов, 12 чтений native history и 40 совпадений; агенты обходятся по очереди. Выдержка результата до 900 символов. Ошибки чтения явно обозначают пропуски, а не успешный полный поиск.
- Непрозрачное одноразовое продолжение привязано к запросу/проекту/агенту, живёт 15 минут; до 8 поисков на окно. Хранятся позиции и идентификаторы, не полные транскрипты. Изменение native истории между страницами возможно.
- `electron/bookmarks.mjs`: `bookmarks.json` v1 в userData, до 5000 записей / 32 МиБ, выдержка 4000, подпись 200, название диалога 500 символов. Запись атомарная и сериализованная для одного пути; flush включён в штатное закрытие. Повреждённый файл или неизвестная версия не перезаписываются. Подпись существующей закладки можно менять даже после удаления папки источника.
- Claude stream может присвоить `api:text:1`, а native история — `api:text:0`. Переход по закладке проверяет сохранённый текст даже при совпавшем ID; fallback разрешён только для единственного подходящего фрагмента внутри того же API message ID. Поисковый snippet не используется как текст закладки.

## Проверки

`tests/history-search.test.mjs`, `tests/bookmarks.test.mjs`, `tests/preload-session.test.mjs` проверяют границы чтения, продолжения, одновременные сохранения, повреждённое хранилище и IPC scope.

`test:history-library` проверяет production renderer: два агента, буквальную кириллицу/спецсимволы, фильтры, страницы, ошибки и запоздалые ответы, переходы/черновики, архив, подписи, перезагрузку и удаление. Отдельная регрессия покрывает смену и коллизию Claude block ID.

`test:history-host` использует настоящий Electron/preload/IPC с подставным Codex и изолированным native JSONL Claude SDK, проверяет readonly поиск, точные ID, границы проектов, закладки после перезапуска. Поддерживает `CODEX_DESK_PACKAGED`. Запросов модели эти тесты не выполняют.
