# Изоляция задач через Git worktree — 2026-09-19

Первый срез пункта 7 [дорожной карты](ROADMAP.md): параллельные задачи одного проекта получают отдельную рабочую копию и ветку, чтобы вкладки не делили одни и те же файлы.

## Использование

В меню проекта (⋮ или ПКМ на папке) — пункт **«Новая задача в отдельной ветке…»**. Диалог просит имя: 1–64 символа, буквы/цифры/точка/дефис/подчёркивание, без пробелов и «..». Git создаёт ветку с этим именем (или использует существующую, если она ни к чему не привязана) и рабочую копию рядом с проектом: `<папка-проекта>.worktrees/<имя>`. Новая вкладка открывается в этой копии, папка добавляется в список проектов; появляется уведомление с путём. Файлы основной папки не меняются, индекс и текущая ветка основной копии остаются прежними.

Ветка, уже занятая другой рабочей копией (например, текущая ветка проекта), отклоняется самим Git; сообщение показывается в диалоге. Папка вне репозитория или без Git получает понятный отказ. Копия внутри самого репозитория намеренно не создаётся, чтобы не появляться в статусе как неотслеживаемая папка.

## Задачи проекта: список, перенос, удаление — 2026-09-19

Пункт меню проекта **«Задачи проекта…»** открывает окно со всеми рабочими копиями репозитория (`worktreeSummary`: путь, ветка, чисто/грязно по `git status --porcelain`, отставание/опережение относительно ветки основной копии по `rev-list --left-right --count`, число открытых вкладок). Основная копия определяется по порядку `git worktree list` (она всегда первая), поэтому окно одинаково работает из основной папки и из папки задачи.

**Перенести в <ветка>** показывает предпросмотр (`git log target..branch`, `git diff --stat target...branch`) и блокирует перенос, если в основной копии есть незафиксированные изменения или в ветке задачи нет новых коммитов. Подтверждение выполняет `git merge --no-edit <branch>` в основной копии; при конфликте выполняется `git merge --abort`, основная копия возвращается к прежнему HEAD, а конфликтующие файлы перечисляются в ошибке. Незафиксированные изменения в копии задачи не переносятся, об этом предупреждает предпросмотр.

**Удалить копию** закрывает вкладки этой папки, затем `git worktree remove` (с `--force` только после явной отметки при незафиксированных изменениях); отметка «удалить и ветку» выполняет `git branch -d`, который сохраняет неслитую ветку. Основную копию удалить нельзя. Host требует, чтобы во вкладках репозитория не было активных ходов, разрешений, терминала и отката; для удаления — чтобы вкладки этой папки были закрыты.

Проверки: `tests/git-worktree.test.mjs` (реальный репозиторий: сводка, предпросмотр, блокировка грязной основной копии, успешный merge, конфликт с abort и неизменным HEAD, отказ удалить грязную копию без force, сохранение неслитой ветки), `scripts/ui-project-tree.mjs` (окно задач, предпросмотр → merge, удаление с закрытием вкладки).

## Что пока не делается

Rebase и cherry-pick отдельных коммитов, а также перенос из одной задачи в другую не предусмотрены: используйте терминал. Закрытие проекта-копии через меню проекта убирает её только из списка, копия остаётся на диске; удаление с диска — через «Задачи проекта…».

## Реализация и проверки

`electron/git-worktree.mjs`: `worktreeName`, `createWorktree` (проверка через `contextFor` из git-reader, те же безопасные аргументы Git без хуков и внешних фильтров), `listWorktrees`. Host `host:createWorktreeSession` создаёт копию от cwd исходной сессии и затем вызывает общий путь `createSession` с новой cwd; ответ содержит `worktree { path, branch, created, root }`. Renderer: `ProjectMenu` → `Workspace.openWorktree` → новая вкладка и папка.

`tests/git-worktree.test.mjs` — настоящий временный репозиторий: соседняя папка, новая и существующая ветка, отказ занятой ветки, дубликата и не-репозитория, неизменный индекс основной копии. Папка «не репозиторий» создаётся в системном temp: `artifacts/` лежит внутри репозитория Codex Desk, и первый вариант теста создал рабочую копию самого Codex Desk (удалена вместе с веткой). `scripts/ui-project-tree.mjs` — пункт меню, пустое имя, ошибка host в диалоге, новая вкладка и папка без запросов модели.
