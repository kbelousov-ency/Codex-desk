# Изоляция задач через Git worktree — 2026-09-19

Первый срез пункта 7 [дорожной карты](ROADMAP.md): параллельные задачи одного проекта получают отдельную рабочую копию и ветку, чтобы вкладки не делили одни и те же файлы.

## Использование

В меню проекта (⋮ или ПКМ на папке) — пункт **«Новая задача в отдельной ветке…»**. Диалог просит имя: 1–64 символа, буквы/цифры/точка/дефис/подчёркивание, без пробелов и «..». Git создаёт ветку с этим именем (или использует существующую, если она ни к чему не привязана) и рабочую копию рядом с проектом: `<папка-проекта>.worktrees/<имя>`. Новая вкладка открывается в этой копии, папка добавляется в список проектов; появляется уведомление с путём. Файлы основной папки не меняются, индекс и текущая ветка основной копии остаются прежними.

Ветка, уже занятая другой рабочей копией (например, текущая ветка проекта), отклоняется самим Git; сообщение показывается в диалоге. Папка вне репозитория или без Git получает понятный отказ. Копия внутри самого репозитория намеренно не создаётся, чтобы не появляться в статусе как неотслеживаемая папка.

## Что пока не делается

Перенос результата (merge/cherry-pick/rebase) выполняется пользователем в терминале или обычными командами Git; оболочка эти операции не запускает. Удаление рабочей копии (`git worktree remove`) и списка задач в интерфейсе пока нет — `listWorktrees` уже читает `git worktree list --porcelain` для следующего шага. Закрытие проекта-копии в оболочке убирает её только из списка проектов, не с диска.

## Реализация и проверки

`electron/git-worktree.mjs`: `worktreeName`, `createWorktree` (проверка через `contextFor` из git-reader, те же безопасные аргументы Git без хуков и внешних фильтров), `listWorktrees`. Host `host:createWorktreeSession` создаёт копию от cwd исходной сессии и затем вызывает общий путь `createSession` с новой cwd; ответ содержит `worktree { path, branch, created, root }`. Renderer: `ProjectMenu` → `Workspace.openWorktree` → новая вкладка и папка.

`tests/git-worktree.test.mjs` — настоящий временный репозиторий: соседняя папка, новая и существующая ветка, отказ занятой ветки, дубликата и не-репозитория, неизменный индекс основной копии. Папка «не репозиторий» создаётся в системном temp: `artifacts/` лежит внутри репозитория Codex Desk, и первый вариант теста создал рабочую копию самого Codex Desk (удалена вместе с веткой). `scripts/ui-project-tree.mjs` — пункт меню, пустое имя, ошибка host в диалоге, новая вкладка и папка без запросов модели.
