# Просмотр изменений — 2026-09-19

Первый этап пункта 4 [плана развития](ROADMAP.md): пользователь подтвердил сравнение «до / после», номера строк и фильтр по запросу, одновременно попросив переделать [composer](MESSAGE_QUEUE.md).

## Поведение

- В «Изменениях» выбирается вся загруженная беседа либо конкретный запрос, подписанный началом пользовательского сообщения. Для старых fileChange без turnId есть «Без привязки к запросу»; принадлежность не придумывается. Более ранние страницы можно подгрузить отдельной кнопкой.
- Поиск по имени/части относительного пути фильтрует карточки файлов. Повторные правки одного файла остаются отдельными записями в одной карточке; фильтр не объединяет их в выдуманный итоговый файл.
- В боковой панели единый diff с двумя колонками номеров. «Развернуть» открывает большой просмотр: «До / после» либо «Единый diff», номера сторон, переход к предыдущему/следующему фрагменту, открытие файла штатным scoped bridge. Ошибка открытия не закрывает сравнение.
- Окно сравнения показывает снимок выбранных правок. Переключение диалога закрывает его; уменьшение окна сохраняет просмотр. Escape закрывает и возвращает фокус; Tab удерживается внутри диалога. Длинные строки переносятся, не расширяя панель.
- `turn/diff/updated` сохраняется отдельно по turnId в текущем запуске. Позднее обновление старого запроса не заменяет сводку последнего, но доступно через фильтр. После resume восстанавливаются исторические fileChange из Codex; сводки, которых история не предоставила, не синтезируются и не пишутся в SQLite/workspace snapshot.

## Достоверность сравнения

Дополнение: отдельный источник [Git](GIT.md) показывает фактические staged/unstaged/untracked выбранной рабочей папки. Прежний источник «Из диалога» сохраняет описанную ниже семантику полученных патчей. Git status/diff добавлен без staging/отката.

Показаны только фрагменты diff, полученные от Codex, а не полные версии файлов и не текущий Git status. Реальный файл мог измениться позже. Просмотр Git и выборочный откат — следующие этапы; кнопок Git/staging/reset здесь нет.

`src/diff-model.ts` разбирает unified hunks с независимыми диапазонами до/после, а также Codex apply_patch с ненумерованными `@@`. Номера выводятся только для полностью проверенного диапазона с совпадающими counts; неизвестные/обрезанные/повреждённые hunks, combined и binary остаются исходным текстом. Отсутствующие номера не заменяются 1..N. Сохраняются rename metadata, `+++`/`---` как содержимое внутри hunks, маркеры отсутствующего newline и пустые стороны add/delete. `changeGroup` и `toUnifiedRows` восстанавливают исходный порядок удалений/добавлений после выравнивания split.

`src/DiffReview.tsx`/`src/diff-review.css` — виды сравнения и большой dialog. Прежний `Diff` для хода работы/поиска чата сохранён, чтобы не менять семантику найденного текста. `src/Panels.tsx` — фильтры/карточки; `src/change-utils.ts` сохраняет turnId каждого FileEdit; `src/useCodex.ts` хранит turnDiffs и защищает последнюю сводку от поздних событий.
