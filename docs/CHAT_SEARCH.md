# Чат и поиск

Запрос: оформление как в мессенджере — пользователь справа, Codex слева; поиск по открытому чату и по диалогам. Предыдущая попытка была заблокирована служебной ошибкой sandbox (`helper_sandbox_lock_failed`, `SetNamedSecurityInfoW … 5`); реализация выполнена после восстановления доступа.

## Сообщения

По выбору пользователя 2026-09-18 прежняя буква «В» (заглушка от «Вы», рядом с такой же подписью была избыточна) заменена пиксельным персонажем. `PixelAvatar.tsx` — локальный SVG 8×8 ячеек, отрисовка 16×16 с crispEdges и цветом currentColor. Не emoji/внешняя картинка: вид одинаков в Windows, обычном чате и архиве, SVG декоративный aria-hidden; подпись «Вы» сохранена.

`Conversation.tsx` подключает `messenger.css`: пользовательский bubble справа до 82% ширины (90% на узком экране), ответ и ход работы слева до 94% (100% на узком). Селекторы `.message`, `.user-message`, `.assistant-message`, `.message-content` сохранены. Изображения, Markdown, код, копирование и scoped файловые ссылки не заменены упрощённым текстом. Работа модели по-прежнему группируется `WorkLog`, автоматически сворачивается перед итоговым ответом; никаких новых пояснений оболочка не сочиняет.

При уменьшении окна до ≤1000px правая панель закрывается, чтобы не перекрывать сообщения справа и composer. Её можно открыть вручную; открытие поиска на узком экране также убирает overlay. Прежде панель автоматически оставалась наложенной поверх чата после resize; обновлён тест project-tree, ожидающий завершения нового поведения вместо повторного нажатия toggle.

## Поиск внутри диалога

`ChatSearch.tsx` заменяет непосредственный `Conversation` в App/ArchiveView, сохраняя его отрисовку. Кнопка в topbar / Ctrl+F работают только в активной вкладке, модальные окна не перехватываются. Sticky toolbar содержит запрос, счётчик, предыдущий/следующий результат, очистку и закрытие. Enter идёт вперёд, Shift+Enter назад, Escape закрывает. Смена thread сбрасывает поиск, переключение вкладок не смешивает совпадения. Автопрокрутка потока App при открытом поиске приостановлена.

Поиск буквальный, без интерпретации запроса как regex: спецсимволы экранируются, используется Unicode case-insensitive поиск по публичному DOM-тексту. DOM Range + CSS Custom Highlight API подсвечивают совпадения без изменения текстовых узлов React и без innerHTML. Работает через inline Markdown, код, пояснения, комментарии и публичные результаты инструментов. hookPrompt/encrypted_content не добавляются к отображению/индексу. При поиске lazy body инструмента монтируется для чтения, открываются только ancestors выбранного совпадения. Автоматически открытые details возвращаются в свёрнутое состояние после очистки/закрытия; ранее раскрытые пользователем сохраняются.

`memo(Conversation)` сохраняет DOM при изменении счётчика/позиции поиска: без этого MutationObserver вызывал revision → Markdown remount → новое событие observer и повторял цикл, из-за чего ссылки постоянно отсоединялись. Поиск наблюдает изменения содержимого для новых сообщений и ленивых тел. Повторные обновления уже выбранного совпадения не возвращают пользователя принудительно к нему.

Навигация прокручивает только свой `.chat-scroll` и вложенные code/output panes. CSS highlights принадлежат активной вкладке и очищаются при закрытии/переключении. Поиск выполняется по загруженным сообщениям: для paginated истории явно отображается ограничение и кнопка дозагрузки более ранней страницы. В архиве дозагрузка использует прежний readonly endpoint, без создания writable-сессии.

## Поиск диалогов

`ProjectSidebar` содержит отдельные запросы обычного списка и архива. При непустом тексте native read начинается через 250 мс; результаты сгруппированы по фактическим cwd, могут содержать папки вне текущего workspace. Открытие активного результата использует прежний createSession/resume и точный thread ID, архивного — только ArchiveView. Меню ⋮ сохраняет действия. Escape/крестик очищают строку. Пагинация, retry, отсутствие результатов и загрузка показаны отдельно.

Фиксированный workspace IPC `searchThreads({query,archived,cursor?})` → `ThreadManagement.searchThreads`. Валидируются непустой query до 500 символов без newline/NUL, boolean archived, bounded cursor. Native `thread/list` получает searchTerm, archived, limit:100, sortKey:'updated_at', modelProviders:[], sourceKinds:['appServer','cli','vscode']; cwd не ограничивается активной вкладкой. По локальной `ThreadListParams` searchTerm — substring extracted title, поэтому UI честно пишет «По названию диалога» и не обещает full-text истории.

Идентификатор запроса + ключ query/archive/revision/active не дают запоздалому ответу подменить новые результаты. Скрытые вкладки не ищут. `searchRevision` обновляется после rename/archive/delete/restore. Пустой поиск не отправляет RPC. Чтение списков не возобновляет беседы, не отправляет модельные запросы и не сканирует вручную JSONL/SQLite.
