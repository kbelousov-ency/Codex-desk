# Экспорт беседы

Кнопка «Экспорт беседы» в шапке текущей беседы и архива открывает окно сохранения. Поддерживаются Markdown `.md` и автономный HTML `.html`, варианты «Переписка» и «Переписка и ход работы». Используются только сообщения выбранной вкладки: пользовательские сообщения, итоговые ответы и старые ответы без `phase`; комментарии/полученные пояснения/публичные результаты инструментов добавляются только при выборе хода работы. Скрытые `hookPrompt`, `encrypted_content` и произвольные поля события не экспортируются. Изображения обозначаются именами или путями, двоичные вложения не встраиваются.

Если история загружена частично, окно явно показывает это, кнопка называется «Сохранить фрагмент…», а файл содержит такое же предупреждение. «Загрузить всю беседу» последовательно читает предыдущие страницы; загрузку можно остановить между страницами. Ошибка или отсутствие новых идентификаторов сообщений останавливают цикл и сохраняют возможность экспорта фрагмента. Закрытие окна/смена вкладки прекращает запросы следующих страниц. Экспорт во время работы разрешён, но помечен как текущий снимок с возможным неполным ответом. Ни один из этих путей не отправляет запрос модели.

`src/ExportConversation.tsx` — окно и HTML; `src/conversation-export.ts` — общий набор публичных полей, Markdown, метаданные, безопасное имя. Native `window.codex.exportConversation({filename,content,format})` открывает Windows Save dialog и записывает UTF-8 в выбранный путь; отмена не отображается как успех, ошибка остаётся в окне. Метки времени и длительности берутся из имеющихся `TurnWork`; неизвестные времена не придумываются. Markdown сохраняет исходную разметку ответов, текст пользователя и вывод инструментов заключаются в fences длиннее встречающихся в содержимом.

HTML форматируется установленными `react-markdown`/`remark-gfm`; `react-dom/server` подгружается отдельным chunk только при выборе сохранения HTML (около 204 КБ/63 КБ gzip на текущей сборке). HTML не выполняет raw HTML, не включает скрипты, удалённые изображения, шрифты и стили. Ссылки разрешены только HTTP(S), недопустимые/local ссылки остаются текстом. В документе задан CSP `default-src 'none'` с разрешением собственного inline CSS. Файл открывается без сети. Экспорт не заменяет исходную историю и не меняет конфигурацию CLI.

Проверки: `tests/conversation-export.test.mjs` — фильтрация переписки/хода работы, скрытые поля, имена/заголовки/fences и времена. `node scripts/ui-conversation-export.mjs` — production renderer: частичный Markdown, последовательная полная история, HTML и его открытие без network requests/исполнения HTML, вложения, отмена/ошибка/повтор сохранения, остановка no-progress пагинации, изоляция Codex/Claude. Скриншоты `artifacts/conversation-export-html.png`, `artifacts/conversation-export-dialog.png`. Native путь отдельно проверяется `scripts/ui-export-host.mjs` на Electron/preload/IPC с временным файлом; модельных запросов нет.
