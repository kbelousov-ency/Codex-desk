# Тематические вкладки настроек

2026-09-22: по просьбе пользователя длинное окно «Ваше рабочее пространство» разделено на четыре вкладки. Точка входа прежняя — кнопка «Настройки» или аккаунт в боковой панели.

- **Агент** (открывается первой): выбранный агент, вход и постоянный токен Claude Code, действующие модель/глубина/доступ и источники значений, возможности, пояснения работы CLI.
- **Подключение**: мастер установки агентов, рабочая папка, выбор исполняемого файла, версия CLI, переподключение и журнал диагностики.
- **MCP**: существующий редактор Codex с проверкой/предпросмотром/сохранением/применением; для Claude — пояснение настройки через CLI.
- **Память**: существующие правила для всех проектов, просмотр, отдельное включение/отключение для Codex и Claude.

Уведомления и обновления сохранили свои отдельные окна. Модель, глубина и доступ по-прежнему меняются под полем сообщения; вкладка «Агент» показывает действующие значения, не записывая их заново.

## Устройство и ограничения

`src/SettingsDialog.tsx` отвечает за окно, вкладки и фокус; содержимое и прежние действия передаются из `src/App.tsx`. Отдельные классы в `src/settings-dialog.css` сохраняют оформление других окон с общей `.settings-modal`.

Высота окна ограничена экраном; заголовок, вкладки и нижняя кнопка остаются на месте. Каждая панель прокручивается отдельно и сохраняет позицию при переключении. Стрелки ←/→, Home/End выбирают вкладку, Tab проходит только по видимым элементам окна, Escape закрывает его и возвращает фокус к кнопке открытия.

Панели остаются смонтированными до закрытия окна. Это сохраняет MCP text/preview/replace и результат незавершённой операции, а также введённый токен Claude и раскрытые тексты памяти. Нельзя связывать `McpSettings.active` с выбранной тематической вкладкой: его effect `[bridge, active]` очищает редактор и инвалидирует generation. Прежняя зависимость от активности самой сессии сохранена; закрытие окна сбрасывает локальные поля как прежде.

Запись правил памяти блокирует переключение вкладок и закрытие окна (включая Escape и фон). При блокировке фокусированной кнопки фокус переводится в видимую панель; `:disabled` исключён из обхода, включая выбранную вкладку с `tabindex="0"`. Состояние `memoryRulesBusy` и явные действия сохранения сохранены; смена тематической вкладки ничего не записывает в конфигурацию и не отправляет модели.

Прежние границы доступа, preview/backup и разделение агентов см. [MCP](MCP.md), [правила памяти](MEMORY_RULES.md), [Claude Code](CLAUDE.md). Процесс поставки — [Nightly/Release](RELEASES.md).

## Проверки

`ui-mcp` проверяет стрелки/Home/End/Tab, одну доступную панель, сохранение текста/preview/replace/результата незавершённого сохранения и доступность навигации/«Готово» при 940×620 и 560×700. `ui-providers` проверяет сохранение авторизации Claude при переходах, `ui-scenarios` — переподключение из новой вкладки. В `ui-memory-rules` добавлен сценарий настоящей SettingsDialog: запись последнего блока Claude, Tab/Shift+Tab из disabled кнопки, цикл последнего summary, запрет Escape/фона/закрытия/переключения, сохранение результата и backup после переходов, возврат фокуса.

Все эти сценарии прошли. Настоящий Electron/preload/IPC и упакованный Nightly проверены `ui-mcp-host` с изолированным config. Модель не вызывалась, пользовательские настройки не записывались. Данные окончательной сборки — [RELEASES.md](RELEASES.md).
