# Идеи развития Codex Desk — 2026-09-19

Новый выбор 2026-09-21 — пункты **1, 3, 5, 6 и 8** из отдельного обсуждения UX: цитирование, оглавление, результат рядом с чатом, карточка итогов и пересечения параллельных задач. Реализованы в исходниках `0.5.0`; [поведение и ограничения](CONVERSATION_UX.md), [поставка](RELEASES.md). Нумерация этого выбора не относится к прежнему списку ниже; прежние решения сохранены.

Идеи предложены после чтения документации и исходников. Сначала пользователь поручил сохранить список и реализовать пункты **1 и 2**. Затем согласовал дальнейшее развитие по предложенному плану, оставив порядок разработки на усмотрение ИИ: ближайший этап — **пункт 3, уведомления**. Последующие этапы — проверка изменений, поиск истории/закладки, просмотр файлов, изоляция задач и действующие настройки. Уже существующие вкладки, история, поиск названий, дерево файлов, MCP, diff, переход в терминал и диагностика служат основой.

Пункты 1 и 2 реализованы в исходниках 2026-09-19 и прошли проверки renderer/host. Поставка — Nightly по обычному процессу; перенос в Release требует отдельного подтверждения. Факты поставки отмечаются в тематических заметках.

1. **Восстановление рабочего места.** Автосохранение вкладок, активного диалога, черновиков, изображений, настроек и позиции чтения после обычного закрытия или сбоя. Основа — снимок обновления Nightly; прежде он применялся только при специальном перезапуске. Поручено 2026-09-19; реализация и проверки — [WORKSPACE_STATE.md](WORKSPACE_STATE.md).
2. **Уточнения и очередь сообщений.** Два явных действия: уточнить текущую задачу через `turn/steer` и отправить следующий запрос после завершения. Видимая очередь с редактированием, отменой и паузой; после восстановления она приостановлена. Прежний UI блокировал отправку при busy, хотя адаптер уже разрешал steer. Поручено 2026-09-19; детали — [MESSAGE_QUEUE.md](MESSAGE_QUEUE.md).
3. **Уведомления.** Реализованы в исходниках 2026-09-19: завершение задачи, вопрос, запрос разрешения, потеря соединения; переход к вкладке, непрочитанный результат, список внимания, настройки звука/событий. Исходной основой были индикаторы вкладок. Проверки и ограничения — [NOTIFICATIONS.md](NOTIFICATIONS.md).
4. **Проверка изменений.** Реализованы [сравнение до/после](CHANGES.md), номера строк, фильтр по запросу, поиск файлов, навигация фрагментов и большой просмотр. Добавлен отдельный [Git status/diff](GIT.md) и [откат одного файла](ROLLBACK.md) к индексу с предпросмотром, резервной копией и undo. Отдельные фрагменты реализованы 2026-09-19 (см. [ROLLBACK.md](ROLLBACK.md#откат-отдельных-фрагментов--2026-09-19)); дальнейший крупный этап — поиск истории и закладки.
5. **Поиск содержимого всей истории и закладки.** Реализованы 2026-09-19: поиск сообщений Codex/Claude, фильтры проекта/агента, выдержки и переход к сообщению, подписи закладок. [HISTORY_LIBRARY.md](HISTORY_LIBRARY.md). Прежний поиск только названий сохранён отдельно. Выбран постепенный native read без постоянной копии транскриптов и без редактирования SQLite; первоначальная идея отдельного локального индекса отложена.
6. **Просмотр файлов внутри приложения.** Реализованы 2026-09-19: Ctrl+P, текст/код с номерами строк, Markdown/картинки, «Спросить о выделении» с видимым текстом в composer. [FILE_VIEWER.md](FILE_VIEWER.md). Внешнее открытие сохранено; переход по введённому номеру строки и подсветка синтаксиса остаются улучшениями.
7. **Изоляция задач одного проекта.** Первый срез реализован 2026-09-19: пункт меню проекта создаёт ветку и соседнюю рабочую копию `<проект>.worktrees/<имя>` и открывает её новой вкладкой — [WORKTREE.md](WORKTREE.md). Список копий, перенос результата (`git merge` с предпросмотром и откатом при конфликте) и удаление копии добавлены тем же днём в окне «Задачи проекта…». Rebase/cherry-pick остаются терминалу. Процессы вкладок независимы, а разные cwd теперь означают и разные файлы.
8. **Действующие настройки и возможности.** Первая часть реализована 2026-09-19: блок «Действующие настройки» в окне настроек показывает агента, модель, глубину, доступ, рабочую папку, путь и версию CLI, а также источник каждого значения (восстановлено из вкладки / сохранённые настройки агента / конфигурация CLI / по умолчанию / выбрано в этой вкладке) и возможности агента (уточнение, сжатие, терминал, импорт MCP, архив). Версия CLI берётся из `initialize` userAgent Codex и `get_binary_version`/`system init` Claude; при расхождении с проверенной версией (`src/cli-versions.ts`) выводится подсказка. Формы дополнительных данных MCP (elicitation) заполняются с 2026-09-19 — см. [MCP.md](MCP.md#формы-подключений-elicitation--2026-09-19). 2026-09-20 в блок добавлены навыки/команды, субагенты и состояние MCP-серверов Claude (`agent/capabilities`: `initialize.commands/agents` и control-запрос `mcp_status`); для Codex состояние MCP остаётся в его блоке импорта с кнопкой «Проверить подключение». Пункт закрыт. Поддержку возможностей проверять по установленному CLI, не обещая универсального discovery API.
