# Свой расход по API: `/v1/me/*`

Свою статистику по роутеру теперь можно забрать себе на комп своим же ключом — без портала и без SSO.
Работает на `https://router.encycam.com`, выкачено 22.09.2026.

## Быстрый старт

Ключ — тот самый, что лежит у тебя в `ANTHROPIC_AUTH_TOKEN` (его выдал портал). Заголовок
`Authorization: Bearer …` или `x-api-key`, в query-строке ключ не принимается специально: Caddy маскирует
заголовки в логах, а строку запроса пишет как есть.

```bash
curl -H "Authorization: Bearer $ANTHROPIC_AUTH_TOKEN" https://router.encycam.com/v1/me/overview
```

```powershell
curl.exe -H "Authorization: Bearer $env:ANTHROPIC_AUTH_TOKEN" https://router.encycam.com/v1/me/overview
```

## Команды

Все `GET`, у большинства есть `?format=json|csv`.

| Команда | Что отдаёт |
|---|---|
| `/v1/me` | почта, ключи, тариф, состояние места |
| `/v1/me/keys` | свои ключи (значений ключей не отдаёт) |
| `/v1/me/models` | какие модели мне разрешено звать |
| `/v1/me/limit` | лимит места: положено, потрачено, осталось, когда сброс |
| `/v1/me/limit/series?bucket=hour\|day` | расход кредитов по времени |
| `/v1/me/usage?period=today\|24h\|7d\|30d\|custom` | сводка окна (по умолчанию `7d`) |
| `/v1/me/usage/models` | то же в разрезе моделей |
| `/v1/me/usage/days?period=7d\|30d\|custom` | то же по суткам (по умолчанию `30d`) |
| `/v1/me/calls?limit=&offset=&model=` | лента своих вызовов, свежие сверху (`limit` до 500) |
| `/v1/me/calls/{call_id}` | один вызов; чужой отдаёт 404 |
| `/v1/me/errors` | только отказы; уходы клиента (499) считаются отдельной цифрой |
| `/v1/me/cache` | попадает ли разговор в кэш префикса |
| `/v1/me/overview` | склейка «кто я + лимит + сутки» одним запросом |

Для `period=custom` — `&start=…&end=…`.

`overview` заведён для тех, кто спрашивает постоянно (строка статуса в редакторе): не надо делать четыре
запроса там, где хватает одного.

## Что стоит знать

**Субъект берётся из токена.** Имени человека нет ни в пути, ни в параметрах — чужое спросить нечем.

**Расход считается по ЧЕЛОВЕКУ**, то есть по всем его ключам сразу (у семнадцати человек их два:
`coder-` от портала и `hermes-` от кита). Лимит — исключение: тариф и место держатся на ключе, поэтому
`/v1/me/limit` отдаёт список по ключам, а не сумму.

**Денег наружу нет**, только кредиты окна — та же величина, по которой человека отсекают.

**Источников три, и ни один не полон сам по себе**, поэтому команды их складывают:

| Источник | Что покрывает | Глубина |
|---|---|---|
| `usage_history` (OmniRoute) | все провайдеры, кроме ушедшего за шов codex | месяцы |
| `core_call` (ядро) | codex за швом; ttfb, длительность, кэш | дни |
| `codex_usage_event` (леджер) | кредиты codex по обоим плечам | с первого сбора |

Вызов лежит ровно в одном журнале, пересечений нет — сверено с леджером, который читает оба и
дедуплицирует по идентификатору вызова. Поэтому слияние — это сложение, а не объединение множеств.
В ленте `/v1/me/calls` у каждой строки стоит `source`: `omniroute` или `core`.

Из-за разной глубины в ответе есть `coverage`: за 30 дней не-codex цифры полные, а лента за швом — нет,
и команда говорит об этом прямо, а не рисует пустоту. Если источник недоступен, команда не падает:
отвечает без этой половины, а `sources` показывает, что прочитано.

## Дальше

Вкладка Usage в портале следующим этапом садится на эти же контроллеры, чтобы цифры в браузере и в
консоли считались одним кодом. Личный ключ браузеру при этом не отдаём — портал остаётся
сервер-сайд-посредником.
